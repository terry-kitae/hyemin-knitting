# 혜민이의 뜨개질 질문방

아이폰에서 약어·한글 이름으로 찾아보는 대바늘 사전. 빌드·계정·서버 없이 GitHub Pages에서 실행됩니다.

## 사용

Safari에서 사이트를 열고 공유 → 홈 화면에 추가. 즐겨찾기와 최근 기록은 해당 브라우저의 localStorage에 보관됩니다. 최초 방문 후 서비스 워커가 기본 자료를 저장합니다. 외부 사진·영상은 온라인 연결이 필요합니다.

## 자료 범위

`data.js`의 `guide`는 한국어 단계별 설명, `reference`는 개요와 외부 자료 안내, `term`은 도안 용어입니다. 모든 항목이 완성된 그림 설명서는 아닙니다. M1R/M1L에는 독자 제작한 방향 개념도가 있습니다. 사진은 재배포하지 않고 원저작자의 페이지로 연결합니다. 영상 검색 링크는 개별 영상의 검증·추천을 의미하지 않습니다.

오른손잡이·일반적인 서양식 코 방향을 기준으로 합니다. 실제 도안의 정의와 범례가 우선합니다.

## 유지보수

`data.js`에서 항목을 추가·수정할 수 있습니다. 오프라인 파일을 변경할 때 `sw.js`의 캐시 버전을 올려 주세요. 외부 라이브러리·추적 스크립트·API 키가 없습니다.

자료: Craft Yarn Council 표준 약어, Purl Soho 뜨개질 튜토리얼. 한국어 요약과 SVG 개념도는 이 프로젝트에서 작성했습니다.
