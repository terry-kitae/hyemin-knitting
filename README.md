# 혜민이의 뜨개질 질문방

아이폰에서 약어·한글 이름으로 찾아보는 대바늘 사전. 빌드·계정·서버 없이 GitHub Pages에서 실행됩니다.

## 사용

Safari에서 사이트를 열고 공유 → 홈 화면에 추가. 즐겨찾기와 최근 기록은 해당 브라우저의 localStorage에 보관됩니다. 최초 방문 후 서비스 워커가 기본 자료를 저장합니다. 외부 사진·영상은 온라인 연결이 필요합니다.

## 자료 범위

171개 항목 모두에 동일한 시점·색상 규칙의 자체 제작 SVG 도해가 있습니다. 총 480개 설명 프레임을 이전/다음, 번호 선택, 확대 화면으로 볼 수 있습니다. 기본 바늘 동작의 개념도와 복잡한 기법의 구조 개념도를 구분합니다. 구조 개념도는 전체 손동작·실 교차·실제 질감을 재현하지 않습니다. 47개 항목에는 별도의 한국어 단계별 설명도 있습니다.

`lessons.js`는 항목별 그림 유형·프레임 설명, `visuals.js`는 공통 도해 엔진입니다. 초록은 기존 코, 주황은 작업 실·강조, 황갈색은 왼바늘, 회청색은 오른바늘, 보라는 보조실·보조바늘입니다. 모든 도해는 외부 이미지 없이 오프라인에서도 표시됩니다.

7개 항목에는 확인한 Purl Soho 공식 영상의 재생 버튼과 원본 링크를 제공합니다. 클릭 전에는 외부 플레이어를 로드하지 않습니다. 영상의 향후 제공·임베드 허용 상태는 제작자 정책에 따라 달라질 수 있습니다. 별도의 한국어 영상 검색은 개별 영상의 검증·추천을 의미하지 않습니다. 사진과 동영상 파일을 복제·재배포하지 않습니다.

오른손잡이·일반적인 서양식 코 방향을 기준으로 합니다. 실제 도안의 정의와 범례가 우선합니다.

## 유지보수

`data.js`에서 항목을 추가·수정할 수 있습니다. 오프라인 파일을 변경할 때 `sw.js`의 캐시 버전을 올려 주세요. 외부 라이브러리·추적 스크립트·API 키가 없습니다.

자료: Craft Yarn Council 표준 약어, Purl Soho 뜨개질 튜토리얼. 한국어 요약과 SVG 개념도는 이 프로젝트에서 작성했습니다.
